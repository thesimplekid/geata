How to get a payment token

Use a Cashu wallet to get a cashuB token from Loading…, in sats, with DLEQ proofs and enough value for the price plus mint fees. The default test mint uses tokens with no real value.

Tokens are sent only when you press Send paid request. They are not saved in your browser.

Each payment spends your token for one request attempt. Excess value is kept; no change or automatic refund. Real-mint tokens spend real funds.
